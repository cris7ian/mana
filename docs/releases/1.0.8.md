# Mana 1.0.8

## What's new

- Pin the Claude subscription usage shortcut to the menu-bar popover. Enable **Show** beside Claude in Settings.
- Open Claude's usage page directly from the popover. No Claude credentials are stored or usage fetched by Mana.
- Keep **Open Settings** available when Claude is pinned without another configured provider.
- Localize quota labels, reset countdowns, and provider errors in English, German, Spanish, and French.

This is a macOS release. The iPhone app is not yet available on the App Store.
