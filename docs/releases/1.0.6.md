# Mana 1.0.6

## What's new

- Added optional Antigravity coding-plan usage through the signed-in `agy` CLI. Mana does not read or store Antigravity credentials.
- Added Antigravity weekly and five-hour quota bars, with an optional provider setting and configurable CLI path.
- Added provider brand icons and a browser link for checking Claude subscription usage.
- Added “Built by Cristian E. Caroli 🍕” to the About window.

## Notes

Antigravity reset timestamps are hidden because their reported values shift between polls. Its Claude/GPT quota is part of Antigravity's coding plan, not a Claude subscription quota.
