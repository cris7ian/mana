Getting started

Ready in a few steps.

A native menu-bar app. No provider CLI installation required.

Get the latest signed release →
  1. 1

    Install Mana

    Open the DMG, drag Mana into Applications, then open the app. Quit an older copy before replacing it.

  2. 2

    Connect your account

    In Settings, sign in with your ChatGPT account for Codex usage, add an OpenCode Go API key, or use both. Codex uses your ChatGPT plan, not an OpenAI API key.

  3. 3

    Check the menu bar

    Select the hexagon to see your usage windows and reset times.

Local by design

Your usage stays on your Mac.

Mana does not save usage snapshots. It stores credentials as private plain-text files in ~/Library/Application Support/Mana/credentials/. Keep backups of that folder private.

Read the setup notes →

Prefer the terminal?

There’s a CLI, too.

The installed app includes the mana command. Link it to your PATH to check usage from your shell. 

mana --provider all --json
