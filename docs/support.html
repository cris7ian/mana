Mana support

Keep your mana in view.

Need help with Mana? Contact Cristian Caroli, Mana’s creator, through the Mana GitHub issue tracker. A GitHub account is required to create an issue. Issues are public.

Include your Mana version, operating system version, provider, and steps to reproduce the problem. Never include API keys, tokens, device codes, account identifiers, raw provider responses, or unredacted screenshots.

Mac downloads and iPhone preview

The current downloads and Homebrew cask are for macOS 13 or later. See the Mac setup and CLI guide.

Mana for iPhone is a pre-release prototype for iOS 18 or later. It is not available on the App Store. It supports Codex and OpenCode Go, with Home Screen and Lock Screen widgets. Antigravity and the command line are Mac-only.

The owner reports successful daily use with live provider access. Public provider permission and App Store-distributed behavior remain unverified. See the iPhone development guide for current release gates.

Connect a provider on iPhone

  1. Turn off Demo in Mana Settings before connecting a real account.
  2. For Codex, start sign-in and approve the displayed device code on OpenAI’s website.
  3. Return to Mana after approval. If the code expires, start sign-in again.
  4. For OpenCode Go, enter your own API key in the provider’s secure field.

Pending Codex approval stays in memory. Force-quitting requires a new code; Cancel stops the current sign-in. Do not copy credentials from another app or CLI.

Usage or widgets look out of date

  1. Unlock your iPhone and open Mana.
  2. Check your internet connection.
  3. Pull to refresh on Usage.
  4. Check the provider’s status in Settings.

Mana refreshes when you open it and every 60 seconds while active. Provider retry delays still apply. Usage is marked stale after 15 minutes or a failed fetch. A failed refresh can leave the last valid values visible.

iOS controls widget and background updates. Widgets are not continuous or guaranteed real-time monitors. Signed-device widget behavior still needs verification. No notification alerts are included.

Demo uses synthetic values and does not contact providers. Sample screenshots do not prove live account access.

Disconnect or change accounts

Use Disconnect in the provider’s settings to remove that provider’s saved iPhone credentials and clear its cached usage. If Mana reports a storage error, unlock the device and retry. An error can prevent credential removal.

Disconnect does not revoke access at the provider or delete your provider account. Manage or revoke provider credentials with the provider. Do not rely on uninstalling Mana to remove Keychain credentials.

Mac credentials use private local plain-text files, not the iPhone storage system. See the privacy policy for storage, network requests, and deletion details.
